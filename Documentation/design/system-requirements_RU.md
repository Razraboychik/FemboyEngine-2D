# Системные требования редактора

[English](system-requirements.md) | [Русский](system-requirements_RU.md)

Это требования к **редактору и dev-сборке**, а не к выпущенной игре. Готовая
2D-игра обычно легче инструментов, которыми её делали. Цифры ниже — целевые
значения, проверяемые пробником требований: пробник печатает измеренную базу
движка, а дельта редактора измеряется на том же reference-проекте.

## Reference-нагрузки

| Нагрузка | Сцена | Работа в редакторе |
|---|---|---|
| Малый проект | 10k спрайтов, 1K текстуры, один viewport, 1080p | небольшая tilemap, скромное аудио |
| Средний проект | 100k спрайтов, 4K текстуры, SDF-освещение, 1440p | большие tilemap, частицы, PIE, voice или multiplayer |

## Минимальные

| Компонент | Цель |
|---|---|
| CPU | 4 ядра / 8 потоков, например Ryzen 3 3100 или Core i3-10100 |
| RAM | 8 ГБ — абсолютный минимум; 16 ГБ — практический минимум с открытыми IDE и браузером |
| GPU | Драйвер Vulkan 1.4 или Metal 2, 2 ГБ VRAM, например GTX 1050, RX 560, Iris Xe |
| Диск | 10 ГБ свободно на SSD; build-дерево добавляет 2-6 ГБ |
| Монитор | 1920x1080 |
| ОС | Windows 10 22H2+/11, Ubuntu 22.04+/24.04, macOS 14+ |

## Рекомендуемые

| Компонент | Цель |
|---|---|
| CPU | 8 ядер / 16 потоков, например Ryzen 7 5800X или Core i7-12700 |
| RAM | 16 ГБ; 32 ГБ для средних проектов с PIE, GI и несколькими панелями редактора |
| GPU | Vulkan 1.4 или Metal 3, 6 ГБ VRAM, например RTX 3060, RX 6600, Apple M1 Pro |
| Диск | 25 ГБ свободно на NVMe |
| Монитор | 2560x1440 |
| ОС | Windows 11, Ubuntu 24.04, macOS 14+ на Apple Silicon |

## Измерение

`fby_requirements_benchmark` собирает синтетическую сцену на 10k и 100k
спрайтов, композитит 120 кадров и печатает среднее время кадра, пиковую
резидентную память и оценку instance-буферов. `fby_editor_requirements_benchmark`
добавляет headless-часть дельты редактора: регистрацию компонентов, обход
инспектора и ограниченную undo-транзакцию на тех же размерах сцены. Он даёт
0.09 / 0.87 мс на проход инспектора, 0.94 / 0.89 мкс на правку и 10.9 / 9.2 мс
на старт PIE при 10k / 100k; стоимость отрисовки ImGui измеряется на
reference-проекте. Запуск dashboard
редактора на reference-GPU занял 291-335 МиБ RSS через 8-12 с; сгенерированные
сцены на 10k/100k сущностей заняли 293.4/302.2 МиБ и загрузились примерно за
0.6/2.1 с. Редактор показал ~82-87/~32-34 FPS на сценах 10k/100k при
2560x1600. Текущие числа — в [performance baseline](performance-baseline.md).

Пробник печатает числа и не падает на медленной CI-машине. Таблица обновляется
по выводу пробника, а не по догадке. 16K/32K ассеты — отдельный
content-heavy-сценарий вне этих целей: текстура 16K RGBA8 — это 1 ГБ, 32K RGBA8
— 4 ГБ без мипмапов, поэтому им нужен отдельный бюджет памяти, а не строка
«максимальные требования».
