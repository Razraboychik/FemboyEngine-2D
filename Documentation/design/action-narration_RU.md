# Озвучка действий

Озвучка действий — речевой канал для игровых событий: подбор предмета, дверь,
удар, смена состояния, враг в радиусе. В отличие от интерфейса эти строки
**не показываются на экране**. Они один раз заводятся в локализации и
произносятся оттуда же, поэтому позже ту же строку можно отдать в субтитры, не
переписывая текст.

## Почему это не экранный диктор

Системный экранный диктор читает дерево доступности: виджеты, фокус, имена. Он
не знает, что за спиной игрока открылась дверь. Этот канал принадлежит диктору
движка. Когда мост активен, они не должны говорить одно и то же дважды: проект
оставляет `narration_focus` за игрой и отдаёт интерфейс ОС-диктору, а озвучка
действий остаётся включённой, потому что у неё нет узла в интерфейсе.

## Модель

`ActionEvent` — POD, который публикуют игровые системы. `ActionNarration`
находит шаблон, применяет правила множественного числа и пространственную
грамматику, фильтрует по политике и ставит строку в `Narrator`.

| Поле | Смысл |
|---|---|
| `TemplateId` | id строки локализации; варианты ищутся через `FindVariant` с `Count` |
| `SubjectNameId`, `ObjectNameId` | локализованные имена для `{subject}` и `{object}` |
| `Count` | положительное значение включает варианты числа и `{count}` |
| `DistanceMeters` | отрицательное — «неизвестно»; иначе `{distance}` и `{meters}` |
| `AngleRadians`, `HasDirection` | 0 — вперёд, положительное — по часовой; восемь секторов |
| `Category` | `NarrationCategory`: взаимодействие, бой, предметы, навигация, состояние, система |
| `Priority` | 0..3, отображается в `NarratorPriority` |
| `DedupeKey` | повтор с тем же ключом внутри окна отбрасывается до сборки текста |

## Шаблоны

Шаблон — обычная строка локализации:

```toml
[ru]
1200 = "{subject} подобрал {count} {object}"
1201 = "{subject} подобрал один {object}"
1202 = "{subject} находится {direction}, {distance}"
```

Плейсхолдеры: `{subject}`, `{object}`, `{count}`, `{direction}`, `{distance}`,
`{meters}`. Неизвестный токен намеренно остаётся в тексте, чтобы автор увидел
опечатку в логе. Пустой фрагмент схлопывает лишние пробелы и пробел перед
знаком препинания, поэтому пропавшее имя не даёт «Предмет ,».

Варианты числа используют принятое в `LocalizationTable` соглашение:
`base + 1` — «one», `+2` — «few», `+3` — «many», `+4` — «two», `+5` — «zero»,
`base` — «other». Поэтому русский и английский работают без новой схемы.

## Пространственные слова

`{direction}` и `{distance}` — слова, а не числа: речь медленная, и «близко»
полезнее, чем «2.4 метра» на ходу. Локализованные id лежат в
`ActionVocabulary`:

```cpp
Fby::ActionVocabulary ScopedVocabulary;
ScopedVocabulary.Directions[0] = LocIds::Ahead;
ScopedVocabulary.Directions[2] = LocIds::Right;
ScopedVocabulary.Near = LocIds::Near;
ScopedVocabulary.Medium = LocIds::Medium;
ScopedVocabulary.Far = LocIds::Far;
Kernel.SetActionVocabulary(ScopedVocabulary);
```

Восемь секторов по часовой от направления вперёд: вперёд, вперёд-вправо,
вправо, назад-вправо, назад, назад-влево, влево, вперёд-влево. Нулевой id
убирает слово, а не подставляет id в речь. Порог расстояний — настройки проекта
(`narration_action_near`, `narration_action_far`); `{meters}` остаётся для игр,
которым нужны числа.

## Политика

`ActionNarrationSettings` живёт в `AccessibilityProfile::actions` и хранится в
ключах `[accessibility] narration_action_*`:

| Ключ | По умолчанию | Действие |
|---|---|---|
| `narration_actions_enabled` | true | главный выключатель слоя |
| `narration_action_categories` | 63 | битовая маска категорий |
| `narration_action_direction` | true | подставлять `{direction}` |
| `narration_action_distance` | true | подставлять `{distance}` |
| `narration_action_min_priority` | 0 | минимальный приоритет; 3 — только критические |
| `narration_action_near` | 3.0 | метры, ниже которых звучит «близко» |
| `narration_action_far` | 12.0 | граница «средне» и «далеко» |
| `narration_action_dedup_ms` | 1200 | окно подавления повторов |

`PublishAction()` требует Blind mode и `narration_world`; проект, выключивший
события мира, останавливает и физические строки, и строки смены тегов. Слой,
как и диктор, работает только в главном потоке.

## Субтитры

`Compose()` возвращает собранную строку до постановки в очередь. Игра, которая
показывает субтитры, может отправить тот же буфер в свой канвас — Deaf mode и
Blind mode опишут событие одной авторской строкой.

## Проверка

`fby_action_narration_test` собирает пак локализации в памяти и проверяет
подстановку, секторы направления и расстояния, английские и русские варианты
числа, неизвестные токены, фильтры категорий и приоритета, дедупликацию и
интеграцию с ядром.
