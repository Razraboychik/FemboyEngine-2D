# Доступность для разработчиков

Это чек-лист интеграции для игры и редактора. Документация для игроков —
[доступность для игроков](accessibility-players_RU.md); контракт и
платформенные детали — в [accessibility](accessibility.md).

## Работа в редакторе

Открой **Project Settings → Accessibility**. У игровой секции три части:

1. **Narrator (game)**: включение речи, фокус/роль/состояние/сцена, события
   мира, темп, глубина очереди, язык и голос.
2. **Action narration (game)**: включение игровых действий, маска категорий,
   слова направления и расстояния, минимальный приоритет, пороги ближнего и
   дальнего расстояния, окно подавления повторов.
3. **Screen reader bridge (game)**: публикация интерфейса в дерево ОС и выбор
   событий фокуса, структуры и состояния.

Список **Voice** показывает установленные голоса с языками и паки
(`pack:<id>`), пункт «Auto» и обновление списка. Это самый быстрый способ
увидеть, есть ли голос для языка на этой машине.

Собственный диктор редактора настраивается в **Editor Settings**: у него свой
голос, темп и политика фокуса, чтобы профиль игры не менял редактор.

## Чек-лист кода

```cpp
Fby::AccessibilityKernel Kernel;
Kernel.ApplyProfile(ScopedProject.accessibility);      // настройки, голос, мост
Kernel.SetActionLocalization(&ScopedLocTable);         // шаблоны и имена
Kernel.SetActionVocabulary(ScopedVocabulary);          // восемь направлений и расстояния
Kernel.SetTtsBackend(Fby::NativeTtsBackend());         // голоса ОС и паки
Kernel.SetBlindMode(true);
Kernel.StartBridge(ScopedWindow);                      // Windows; на других платформах no-op
```

Каждый кадр, в главном потоке:

```cpp
Kernel.ProjectCanvas(ScopedCanvas);   // дерево, озвучка фокуса, мост ОС
Kernel.FlushSpeech();                 // переносит события мира в диктор
Kernel.Actions().Advance(DeltaTime);  // двигает часы дедупликации действий
```

Игровые системы публикуют `Fby::ActionEvent`, а не готовую строку: слой сам
подставляет шаблон, правила числа и пространственные слова. Id шаблонов и
соглашение о вариантах описаны в
[озвучке действий](action-narration_RU.md).

`FlushSpeech()` — жёсткий контракт главного потока. SAPI привязан к apartment,
AVSpeech владеет очередью; никогда не вызывай диктор из рабочего потока.

## Настройки и хранение

Игра хранит всё в профиле доступности проекта. Редактор пишет те же ключи в
файл проекта и зеркалит свои настройки в `editor.ini`. Полная таблица ключей —
в [справочнике настроек редактора](../md/ru/EditorSettingsReference_RU.md);
ключи речи — `narration_*` и `narration_action_*`.

## Языки

Движок документирует 42 языка и подбирает лучший установленный голос по языку
контента: точный тег, основной сабтег, английский, первый установленный голос.
Каталог и правила — в [языках речи](speech-languages_RU.md). Чтобы добавить
язык, расширь `SpeechLanguages.cpp`, таблицу в этом документе и
`fby_speech_languages_test`.

## Проверка интеграции

- `fby_accessibility_narrator_test`: дерево, проекция, политика диктора, выбор
  голоса, заглушка моста.
- `fby_speech_languages_test`: каталог, нормализация, фолбэк и выбор голоса для
  всех 42 языков.
- `fby_action_narration_test`: шаблоны, плюрализация, пространственные слова,
  категории, дедупликация.
- `fby_tts_voicepack_test`: манифест, маршрут `pack:` и протокол хелпера.
- `fby_tts_thread_test` и `fby_ui_accessibility_test`: контракт главного
  потока, субтитры и политика blind/deaf.

После сборки запускай их через `ctest -R "accessibility|narration|speech|tts"`.

## Платформенные заметки

| Платформа | Речь | Мост в экранный диктор |
|---|---|---|
| Windows | SAPI + OneCore (WinRT) | UI Automation, реализован |
| Linux | speech-dispatcher, fail-closed | провайдер AT-SPI2 реализован (libdbus); проверка сборки и рантайма в Linux CI |
| macOS | AVSpeech | провайдер NSAccessibility реализован; проверка сборки и рантайма на macOS впереди |

Движок не линкует хелпер голосового пака: паки — отдельные процессы, их
лицензии остаются вне условий MPL 2.0 движка. См.
[голосовые паки](voice-packs_RU.md).

## Интеграция для игроков

Игра должна предоставить:

- путь первого запуска, который можно пройти без зрения;
- экран настроек с диктором, языком, голосом, темпом, категориями действий и
  субтитрами;
- документированную горячую клавишу для выключения или повтора речи;
- способ установить или указать голосовые паки с видимой лицензией пака.

Движок даёт переключатели и речь; обнаружение — за игрой.
