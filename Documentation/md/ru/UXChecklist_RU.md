# Чеклист проверки UX редактора

Этот чеклист превращает проверку удобства редактора в повторяемый проход. Он
покрывает то, что не оценивают unit-тесты: фокус, доступность с клавиатуры,
сохранение layout, DPI, сообщения об ошибках, границы undo и переходы PIE.

Проход выполняется перед release candidate на Windows при масштабе 100%, 150% и
200%, а также один раз со вторым монитором. Каждый сбой фиксируется с именем
панели, точным действием и наблюдаемым результатом.

## 1. Общая оболочка

| Проверка | Условие прохождения |
|---|---|
| Запуск без проекта | Welcome или выбор проекта доступны; закрытие оставляет рабочее окно |
| Открытие проекта | Dock layout восстанавливается; панели не перекрываются и не имеют нулевой размер |
| Закрытие и повторное открытие | Размер окна, dock layout и видимость панелей сохраняются |
| Навигация только клавиатурой | Все меню и диалоги доступны без мыши |
| Фокус после закрытия модалки | Фокус возвращается в элемент, который её открыл |
| Второй монитор | Панели переносятся без потери масштаба и ввода |
| Свернуть и восстановить | Рендер продолжается, нет device loss и дублирования ввода |

## 2. Проход по панелям

Каждую панель нужно открыть, закрыть и открыть снова. Панель должна сохранять
рабочий размер по умолчанию и не забирать фокус у вьюпорта.

| Область | Проверки |
|---|---|
| Hierarchy | Создание, переименование, смена родителя, удаление; multi-select; поиск; drag во вьюпорт |
| Inspector | Все компоненты сворачиваются и разворачиваются; правка отменяется одним действием; неверное значение показывает понятное сообщение |
| Content Browser | Переход по папкам, reimport, переименование и перемещение; отсутствующий ассет показывает ошибку, а не пустую плитку |
| Viewport | Orbit/pan/zoom; режимы гизмо; контур выделения; очень маленький и очень большой размер |
| Console | Фильтр по уровню и категории; очистка; копирование строки; длинная строка переносится и не скрывает элементы управления |
| Profiler и Stats | Старт/стоп; значения обновляются; нет всплеска аллокаций при открытой панели |
| Material Graph | Создание узлов, соединение, разрыв, undo, redo, сохранение и загрузка |
| Animation Graph | Добавление состояния и перехода, удаление узла, компиляция, чтение ошибки |
| AI State Tree | Добавление leaf и selector, соединение, удаление поддерева, компиляция, сохранение и загрузка |
| Project Settings | Изменение значения, отмена, повторное открытие; старое значение возвращается; commit сохраняется |
| Панели текста и шрифтов | Отсутствующий глиф, длинный текст, RTL-пример и крупный размер остаются рабочими |

## 3. Undo и redo

Для каждого изменяющего действия нужно один раз нажать undo и redo.

Проверка проходит, когда:

- документ возвращается точно в состояние до действия;
- redo восстанавливает те же идентификаторы;
- выделение сохраняется или возвращается к разумному объекту;
- отменённый диалог не создаёт запись undo;
- многошаговый drag создаёт одну запись, а не по одной на кадр.

## 4. PIE

| Проверка | Условие прохождения |
|---|---|
| Запуск PIE | Состояние редактора не меняется; симуляция стартует из авторской сцены |
| Остановка PIE | Авторская сцена возвращается; нет дублированных сущностей и утёкших компонентов |
| Десять запусков и остановок | Память и число сущностей остаются стабильными |
| Правка во время PIE | Редактор отказывает или явно ставит изменение в очередь; нет тихой порчи данных |
| Остановка с ошибкой | Ошибка видна, редактор остаётся рабочим |

## 5. Ошибки и пустые состояния

- У каждого пустого списка есть объяснение и следующее действие.
- Ошибка импорта называет файл, строку или поле, если они известны, и причину.
- Неудачное сохранение оставляет предыдущий файл целым.
- Отсутствующий ассет, шрифт или текстура показывают placeholder и пишут одну
  ошибку, а не по одной на кадр.
- Длинный или не-AS

## 6. Визуальная и accessibility-проверка

- Контраст текста читаем во всех темах.
- Кольцо фокуса видно на каждом интерактивном элементе.
- Порядок Tab совпадает с визуальным порядком.
- Tooltip не закрывает элемент, который описывает.
- Layout выдерживает масштаб шрифта и high-DPI монитор.
- Ни одна панель не передаёт ошибку только цветом.

## 7. Подписание

Записать версию сборки, масштаб, GPU и список пропущенных проверок. Release
candidate принимается только тогда, когда у каждого пропуска есть причина, а у
каждого сбоя — ответственный.
